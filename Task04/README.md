# Task 4 – Arithmetic and Stream Operator Overloading

## Aim
Demonstrates Money stored in integer paise and overloaded +, -, +=, ==, <, <<, and >> operators.

## Files
- `q4.cpp` — C++ source code.
- `README.md` — instructions and summary.

## Compile
```bash
g++ -std=c++17 -Wall -Wextra q4.cpp -o q4
```

## Run (Linux/macOS/Git Bash)
```bash
./q4
```

## Run (Windows PowerShell)
```powershell
.\q4.exe
```
