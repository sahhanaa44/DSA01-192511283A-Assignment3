# Task 2 – Copy Constructors: Shallow and Deep Copies

## Aim
Demonstrates deep-copy construction, copy assignment, self-assignment protection, and destructor cleanup for a dynamic medicine array.

## Files
- `q2.cpp` — C++ source code.
- `README.md` — instructions and summary.

## Compile
```bash
g++ -std=c++17 -Wall -Wextra -fsanitize=address -g q2.cpp -o q2
```

## Run (Linux/macOS/Git Bash)
```bash
./q2
```

## Run (Windows PowerShell)
```powershell
.\q2.exe
```
