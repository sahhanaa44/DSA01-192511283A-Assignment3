# Task 6 – Rules of Operator Overloading

## Aim
Demonstrates a dynamically allocated Text class with copy constructor, copy assignment, destructor, concatenation, comparisons, stream output, and self-assignment protection.

## Files
- `q6.cpp` — C++ source code.
- `README.md` — instructions and summary.

## Compile
```bash
g++ -std=c++17 -Wall -Wextra -fsanitize=address -g q6.cpp -o q6
```

## Run (Linux/macOS/Git Bash)
```bash
./q6
```

## Run (Windows PowerShell)
```powershell
.\q6.exe
```
