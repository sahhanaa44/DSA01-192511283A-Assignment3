# DSA01-192511283A-Assignment3

C++ Assignment 3 covering constructors, destructors, dynamic memory, copy semantics, and operator overloading.

## Folder Structure
- `Task01/` — Constructors and constructor overloading
- `Task02/` — Deep copying and Rule of Three
- `Task03/` — Dynamic constructors and destructors
- `Task04/` — Money arithmetic and stream operators
- `Task05/` — Increment, comparison, and subscript operators
- `Task06/` — Text class and operator overloading rules
- `Task07/` — Complex numbers and AC impedance

## Compiler
C++17 or later. Example compiler: g++.

## Compile and Run
Open a terminal in each task folder and follow that folder's README. Example:

```bash
cd Task01
g++ -std=c++17 -Wall -Wextra q1.cpp -o q1
./q1
```
