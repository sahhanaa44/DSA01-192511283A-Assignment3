# Task 3 – Dynamic Constructors and Destructors

## Aim
Demonstrates a dynamically allocated auditorium seat map, booking and cancellation, stack/block/heap object lifetimes, and destructor cleanup.

## Files
- `q3.cpp` — C++ source code.
- `README.md` — instructions and summary.

## Compile
```bash
g++ -std=c++17 -Wall -Wextra -fsanitize=address -g q3.cpp -o q3
```

## Run (Linux/macOS/Git Bash)
```bash
./q3
```

## Run (Windows PowerShell)
```powershell
.\q3.exe
```
